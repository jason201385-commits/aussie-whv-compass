關於本站

一份寫給後來者的攻略——因為我當初也希望有人這樣寫給我。

準備打工度假的路上，你會遇到兩種資訊：一種是滿滿業配和代辦廣告的「攻略」，另一種是散落在論壇、社團裡真假難辨的隻字片語。這個網站想做第三種：

  • 永久免費——不賣課程、不接代辦業配、不放追蹤廣告。
  • 可查證——重要數字附官方來源連結和「最後更新」日期，你可以（也應該）自己點進去確認。
  • 可修正——全站在 GitHub 開源。政策變了、數字舊了、寫錯了，任何人都能提出修改。

我自己受惠於許多前人的無私分享，這個網站是把這份幫助傳下去的方式。

本站唯一的收入來源是自願贊助（donate），用來支付網域費用和一點咖啡錢。不贊助也能使用全部內容，永遠如此。

一起維護這份攻略

這份攻略最大的敵人是「過時」。簽證費每年 7 月調漲、稅率會改、最低薪資年年變。如果你發現任何過時或錯誤的內容：

  1. 到本站的 GitHub 儲存庫開一個 Issue 告訴我們哪裡錯了（附上官方來源最好）；
  2. 或者直接改好送 Pull Request——每一頁的 HTML 都刻意寫得很簡單，不需要會寫程式也看得懂；
  3. 不會用 GitHub 也沒關係，用儲存庫首頁列的聯絡方式告訴我們就好。

網站統計與隱私

正在確認網站統計設定。

本站採用先同意、才載入的 Google Analytics 4 架構。未同意時不會載入 Google tag；選擇「不要載入」後，後續頁面也不會載入。你的選擇只存在這個瀏覽器。

允許後，Google Analytics 可能收到瀏覽頁面、裝置／瀏覽器資訊、概略地區與基本互動。本站不設定 User-ID、不做廣告個人化，也不傳送需求單、Email 內容、自我釐清答案、清單內容或站內搜尋字詞。站內搜尋只記錄結果數與第一個結果所屬頁面。

GA4 啟用後，你可以從每頁頁尾的「網站統計設定」改變選擇。撤回只能停止之後的載入與量測，無法收回先前已送出的統計資料。Google 如何處理資料請看Google Analytics 資料保護說明。
