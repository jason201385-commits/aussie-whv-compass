關於本站

一份寫給後來者的攻略——因為我當初也希望有人這樣寫給我。

準備打工度假的路上，你會遇到看似免費、實際只為把人導向付費服務的內容，也會遇到散落在論壇、社團裡真假難辨的隻字片語。這個網站選擇把公開內容與商業合作的界線寫清楚：

  • 公開攻略免費——本站攻略與核心工具不設付費牆，不會因為是否購買服務而少給關鍵資訊。
  • 客製合作可收費——受邀課程、講座、工作坊、網站與數位工具或內容製作，可在確認範圍、費用與交付後承接。
  • 合作必須透明——付費不代表能買到推薦、排名或有利說法；若有商業關係，會清楚標示，不影響官方事實的呈現。
  • 可查證——重要數字附官方來源連結和「最後更新」日期，你可以（也應該）自己點進去確認。
  • 可修正——全站在 GitHub 開源。政策變了、數字舊了、寫錯了，任何人都能提出修改。

我自己受惠於許多前人的無私分享，這個網站是把這份幫助傳下去的方式。

想合作，或想找 Jason 幫忙

不確定該找誰、想邀請課程或講座、想一起做對打工度假者有用的內容，或有網站與數位工具需求，都可以先說明。私人或可能收費的合作用 Email，適合公開共編的內容用 GitHub；我會親自看，再判斷是否適合承接。

客製課程、講座與工作坊學校、社群或團隊可先說明對象、主題、形式、日期與希望成果 內容、資料與社群合作第一手經驗、官方資料、活動或社群資源，希望一起整理成可查證的公開內容 網站與數位工具協助先描述目前卡點、希望達成的結果與時間，不需要先懂技術術語

收費合作怎麼成立：第一封信只用來確認需求。若適合承接，雙方還要另外確認工作範圍、時程、費用、交付方式與取消條件；沒有確認前，不算委託成立。

本站不提供任何形式的簽證或移民代辦。本站目前不是澳洲註冊移民代理或澳洲執業律師，因此不提供個人簽證選項建議、不準備或代填簽證申請，也不代表申請人處理簽證事項；不論是否收費都一樣。

可以提供中立轉介，但不是替你選答案。目前先提供 OMARA 官方名冊，讓你自行查驗姓名、MARN 與聯絡方式；目前沒有指定合作代理，也沒有啟用佣金轉介。若未來與特定專業人士建立商業轉介關係，會在連結旁直接揭露；是否收取轉介費會先完成法律與稅務確認，確認前不啟用。未經你明確同意，不會把你的聯絡方式或個案內容交給任何人。你仍直接與該專業人士簽約、付款並自行決定是否採用，本站不保證簽證結果。

一起維護這份攻略

這份攻略最大的敵人是「過時」。簽證費每年 7 月調漲、稅率會改、最低薪資年年變。如果你發現任何過時或錯誤的內容：

  1. 到本站的 GitHub 儲存庫開一個 Issue 告訴我們哪裡錯了（附上官方來源最好）；
  2. 或者直接改好送 Pull Request——每一頁的 HTML 都刻意寫得很簡單，不需要會寫程式也看得懂；
  3. 不會用 GitHub 也沒關係，用儲存庫首頁列的聯絡方式告訴我們就好。

網站統計與隱私

正在確認網站統計設定。

本站採用先同意、才載入的 Google Analytics 4 架構。未同意時不會載入 Google tag；選擇「不要載入」後，後續頁面也不會載入。你的選擇只存在這個瀏覽器。

允許後，Google Analytics 可能收到瀏覽頁面、裝置／瀏覽器資訊、概略地區與基本互動。本站不設定 User-ID、不做廣告個人化，也不傳送需求單、Email 內容、自我釐清答案、清單內容或站內搜尋字詞。站內搜尋只記錄結果數與第一個結果所屬頁面。

GA4 啟用後，你可以從每頁頁尾的「網站統計設定」改變選擇。撤回只能停止之後的載入與量測，無法收回先前已送出的統計資料。Google 如何處理資料請看Google Analytics 資料保護說明。
