## 維護同一份答案

編輯 `answers.json`，不要直接改產生出的答案卡。每筆來源只支持卡片所列的範圍，不代表整頁、所有租屋安排或所有簽證資格。法規、收費與權利義務以官方原文為準，遇差異先將 `status` 改成 `needs-review`，說明缺少哪個條件，不讓舊結論繼續冒充現行規則。

1. 人工閱讀 sourceIds 對應原文，核對適用對象與例外；官方連結 HTTP 200 不是內容已確認。
2. 改摘要、條件、下一步與查核日期。reviewDue 是下次維護期限，不能當內容一定沒變的保證；未重讀不得改 sourceCheckedAt。
3. 依序執行：

```sh
python scripts/build_task_answers.py
python scripts/build_i18n.py
python scripts/build_search.py
python scripts/build_seo.py
python scripts/build_task_answers.py --check
python scripts/build_search.py --check
python scripts/build_seo.py --check
python scripts/test_task_answers.py
node --test scripts/test_task_answers.cjs
```

瀏覽器到期會隱藏短摘要，仍提供條件與來源；靜態與純文字版本保留核對日期。到期內容須人工更新為 needs-review 並重新發布，不能以瀏覽器日期代替編輯維護。沒有替站長開啟背景監控、寄信或排程。

## 本輪來源與界線

官方來源網址及卡片適用條件完整登記於 `../answers.json`。交通比較採八城官方／公共交通查詢入口，不宣稱某城市最好、房租多少或職缺充足。Workforce Australia 只核對求職入口，不保證職缺結果。資金試算是本站整數金額算術，參考 Moneysmart 的支出分類，不是政府核准的模型。TFN 與到職資料以 myGov 官方說明為入口；本輪不承諾簽證資格、稅率、辦理時限或補助資格。

## 真人測試：先觀察，再幫忙

建議邀請 6–8 位第一次赴澳者或抵澳未滿一個月者。這是找操作障礙的小樣本，不可當市場代表。先詢問是否願意參與；不自動寄邀請、不要求真實收入、地址、帳號、證件或薪資單。資料使用情境數字。錄音、錄影需另外同意，報告用代號，不存聯絡資訊。

開場可說：「這是在測網站，不是在考你。請用自己的手機找答案，邊操作邊說你在想什麼。遇到卡關我先不教你，因為那是網站要改的地方。」

從首頁開始，記錄開始時間與第一次正確行動；首次回答前不要教操作。每人可選五題，輪換順序。30–60 秒找到正確入口是待驗證目標，不是現有成效。

|---|---|---|

單次記錄格式（不含個資）：代號｜階段｜任務｜秒數｜首次入口｜是否找對｜理解假設｜卡點｜協助次數。

### 1. 不只問帶多少錢，先算沒有收入能撐多久

準備去澳洲，最難回答的可能不是「能賺多少」，而是「還沒領到第一份薪水之前，我能不能安心生活？」

澳打指南針新增一個免費情境試算：把可動用現金、還沒支付的費用、押金、保留金與每週開支分開，就能看見自己的無收入緩衝期。金額只在頁面計算，不儲存、不上傳。不是建議準備金，也不保證幾週能找到工作。

https://www.aussiewhvcompass.com/cost.html#runway

### 2. 落地第一週，不必一次背完四個名詞

TFN、銀行、myGov、super 看起來都重要，先搞懂用途，比死背先後順序更有幫助。

我們把第一週的用途說明、到職需要準備的資料，以及官方辦理入口放在一起。不是代辦，不收你的證件或帳密；有個別身分條件時回到官方來源核對。

https://www.aussiewhvcompass.com/prep.html#first-week

### 3. 接工作前，先把條件問清楚

看到雇主有 ABN，就代表薪資、工作內容和集簽都沒問題嗎？企業登記查得到，不等於每一份邀約都已被驗證。

接工作前先核對雇主、職務、僱用型態、工時與薪資依據，並保留書面條件。澳打指南針整理了核對入口；涉及指定工作，417 和 462 請分開看適用規則。免費使用，不替個案下合法或合資格結論。

https://www.aussiewhvcompass.com/work.html#verify
