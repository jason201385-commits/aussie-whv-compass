## 0.2 P1-32 站內搜尋與 Cloudflare 單一 AI 入口

此節是現行流程，優先於 §0.1 與後續歷史設計骨架；取代關係與部署證據見 D-2026-10-09-03，完整行為契約見 `SPEC.md` §1.2。原有安全、資料最小化、白名單與固定文字原則仍適用。

- 一般搜尋接受 2–200 字，先用本站公開索引、編輯答案與可靠主題訊號導向既有內容；不載入 Turnstile、不送問題、不消耗每日模型額度。
- `assistMode: "local"` 為未完成遠端驗收前的公開設定。只有明確 `cloudflare` 且遠端設定齊全，才提供未命中後的獨立 AI 選項；缺值、舊模式或未知值都保留本機搜尋，不隱性切換供應商。
- 選「請 Cloudflare AI 找站內連結」後才揭露 Cloudflare 與載入驗證，再按確認才送 4–200 字的問題；修改、取消、關閉即撤銷待送狀態，晚到的 token 或回覆不能使它恢復。
- Worker 只使用 Cloudflare 原生 `AI` binding 與受限模型 ID；新路由 `/api/assist/cloudflare`。舊 `/api/assist` 固定 410，不讀 body、不呼叫模型或記錄文字。
- 真實模型品質、配額與正式部署需要個別驗收；local 可獨立運作，mock 與 dry-run 不代表 Cloudflare 推論已啟用。

## 0. 目標與成功定義

- 目標（站長原話）：使用者進站能快速釐清自己的澳打問題並找到資訊；「板面太豐富，文字太多反而失焦」；
  「最終目的是讓活人可以彼此連結」。
- 成功定義（沿用 SPEC §1.5 自願任務測試）：新訪客 30 秒內找到正確情境與第一個安全下一步；
  釐清器完成率；AI 兜底被觸發的比例應低（點選路徑優先）。實際數字要等量測上線後才有基線。

1. 釐清器任何一層都不得提供個人簽證資格、法律、醫療、稅務判定；只能導向站內頁面、官方出口與專業名冊。
2. 緊急安全出口（立即危險、剛匯款、威脅／扣證件、簽證到期）常駐在漏斗之上，任何狀態下一鍵可達。
3. 零打字優先：漏斗前三層全部是 chips／單選；打字框只在最後一層出現，且先顯示站內搜尋結果。
4. 無 JavaScript 時漏斗退化為靜態 `<details>` 分流（沿用現有 `.route-guide` 模式），內容頁連結完整可用。
5. 不新增框架、不新增建置步驟、不新增第三方腳本（CWA 例外，須登錄 SDD §2 與 SPEC §3）。
6. 站長服務招攬不進漏斗；贊助只留 About。
7. 商業關係不得影響出口順序；社團入口須登錄 `third-party-register.json`。

## 4. Cloudflare AI 兜底規則（C-4／P1-32）

- **觸發**：一般查找先在本機處理；可信結果直接呈現。沒有可信結果且 Cloudflare 模式設定齊全，才出現獨立 AI 動作。
- **明示**：使用者選擇 AI 後，呈現 Cloudflare Workers AI、資料處理範圍與不輸入個資的提醒；此時才載入 Turnstile。完成驗證且按下「同意並送給 Cloudflare AI」才送出。
- **內容**：前端只送問題與驗證 token；後端只把問題與固定站內目錄交給原生 binding，不附瀏覽紀錄、清單或個案文件。
- **後端**：`POST /api/assist/cloudflare`；Origin、已知 IP、Turnstile、HMAC 限流、D1 每日聚合計數、設定／模型 ID、逾時與回覆大小都按 `SDD.md` §3.1 驗收。舊 `/api/assist` 固定 410，不讀取或轉發舊客戶端的 body。
- **回覆**：模型只能選站內白名單連結，所有可見文字由固定模板組成；安全與個人判定題先走既有固定出口。成功回應的供應商必須是 `cloudflare`，不符時只呈現固定查找備援。
- **撤銷**：編輯問題、取消或關閉會清除待送文字、token 與計時器、取消請求；即使遠端無法取消，晚回覆也不得重畫或搶焦點。驗證腳本晚載入同樣要檢查已失效的互動狀態。
- **驗收**：local／缺設定可正常搜尋；明確同意之前零模型請求、選擇 AI 前零 Turnstile；錯誤可繼續搜尋；no-JS 不顯示無作用的輸入入口。實作回放與正式啟用證據分開記錄。

## 5. 社團目錄（C-5）

- 資料：既有首頁 9 個公開入口（1 LINE＋8 Reddit）為種子；擴充時每筆登錄 `third-party-register.json`
  並附查核日期；FB 只做平台搜尋連結，不列具體社團除非通過 SDD §3.2 上架欄位。
- 推薦邏輯：地區（州別／城市）×需求（找房、找工作、生活交流、買賣）→ 排序依 SDD §3.2 自然排序，
  不依付費；無合適入口時顯示平台搜尋。
- 邊界：不做站內配對、佈告欄、私訊、會員；不作求職／租屋查核；不作緊急支援或專業轉介。

## 6. 量測（C-6）

- Cloudflare Web Analytics：無 cookie、不需同意；啟用時登錄 SDD §2 外部依賴與 SPEC §3；beacon token 是公開值，可進 repo。
- GA4：維持 Basic Consent；填 ID 前完成敏感頁排除清單（SPEC §1.5）；D+ 既有 7 類別保留。
- 釐清器專屬指標（先設計，後量測）：各層完成率、出口點擊、AI 觸發率、超額次數；
  以 D+ 白名單 key 或 CWA 事件實作，不建立個人層級資料。
