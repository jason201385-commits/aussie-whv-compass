## 一、出發前時間軸

[Section permalink](https://www.aussiewhvcompass.com/prep.html#timeline)

### 下簽之前：只做不用花大錢的事

[Section permalink](https://www.aussiewhvcompass.com/prep.html#main-content)

- 簽證審理近年變慢且無明確時程（見[簽證頁](https://www.aussiewhvcompass.com/visa.html#changes)）——**拿到核准信之前：不辭職、不訂機票、不簽任何退租約**。

- 可以先做的：確認護照效期涵蓋整個停留期間、做[自我釐清](https://www.aussiewhvcompass.com/why.html)、每天練[英文](https://www.aussiewhvcompass.com/english.html#before)、存錢。

### 下簽之後（建議出發前 1–3 個月完成）

[Section permalink](https://www.aussiewhvcompass.com/prep.html#main-content)

| 事項 | 說明 |
| --- | --- |
| **保險（最重要）** | 台灣人在澳洲**不能用 Medicare**，保險是行前必辦、不是落地再說——怎麼選見[健康安全頁](https://www.aussiewhvcompass.com/health.html#insurance) |
| 機票 | 單程可（但入境官可能想看你有買回程的錢——即財力證明的一部分） |
| 國際駕照 | 監理站當天可辦；部分州對中文駕照另要求 NAATI 認證譯本，打算開車的人建議一併備妥 |
| 牙醫全面檢查 | 澳洲牙科極貴（補一顆牙常見 $150–300+），出發前把牙處理好是最划算的一筆投資 |
| 英文履歷 | 澳式格式：1–2 頁、無照片、無生日（見[找工作](https://www.aussiewhvcompass.com/work.html#resume)）；出發前就改好並背熟內容 |
| 學經歷／證照英譯 | 有專業技能（廚師、技工、醫療相關）的人準備英文版證明與推薦信——這是之後走[擔保路線](https://www.aussiewhvcompass.com/pr.html)的本錢 |
| 銀行開戶研究 | 「出發前線上預開」的服務**各銀行政策近年變動大、隨時可能停辦**——出發前直接查你屬意銀行官網的 “Moving to Australia” 頁面確認現行做法；查不到或已停辦也沒關係，**抵澳後帶護照臨櫃開戶本來就可以**，別因此找付費代辦 |
| Wise 或同類帳戶 | 台澳之間轉錢用中間匯率、手續費透明，比銀行電匯划算（民間常用做法，非官方推薦） |

## 二、錢怎麼帶（與怎麼換）

[Section permalink](https://www.aussiewhvcompass.com/prep.html#money)

- **總額**：官方門檻約 A$5,000＋機票錢；實際建議 A$7,000–10,000——主要理由是**落地找工空窗常達 2–6 週**，詳見[物價與薪水](https://www.aussiewhvcompass.com/cost.html#budget)。

- **現金只帶 A$200–300**（機場交通、SIM 卡、第一餐），其餘放帳戶。澳洲幾乎全面刷卡，大額現金只是安全風險。

- **出發前換一點澳幣現鈔就好**：在臺灣的銀行看的是「現金匯率」（比「即期匯率」差，因為含現鈔處理成本）；到機場分行才換通常又更差。大部分的錢留在帳戶裡，落地開好澳洲帳戶後再轉，總成本幾乎都更低——三種轉法與費用結構見[換匯與匯款](https://www.aussiewhvcompass.com/cost.html#exchange)。

### 帶現金過海關：兩邊的規定都要知道

[Section permalink](https://www.aussiewhvcompass.com/prep.html#money-customs)

- **臺灣出境**：外幣現金（含港幣、澳門幣）合計超過**等值美金 1 萬元**要向海關申報——申報後可全數帶出；**沒申報的話，超過的部分直接沒入**。新臺幣現鈔上限 10 萬元，超過的部分就算申報也不准帶出。可在出境前於「關港貿單一窗口」線上預先申報。

- **澳洲入境**：現金加無記名旅行支票等合計**澳幣 1 萬元以上**（含外幣折算）要在通關前完成線上申報，未申報可處罰金或監禁。**把錢分拆給同行親友以避開申報（structuring）本身就是違法行為**，不是聰明做法。

- 經銀行或合法匯款業者轉帳**不需要自己申報**（業者會依法申報）——這也是「大額走轉帳、現金只帶小額」的另一個理由。

來源：[財政部關務署臺北關・洗錢防制物品出境限量規定](https://web.customs.gov.tw/taipei/singlehtml/3394?cntId=cus2_3394_3394_1359)・[AUSTRAC Moving money overseas](https://www.austrac.gov.au/general-public/moving-money-overseas)｜2026-09-01 查核

## 三、行李：帶什麼、不帶什麼

[Section permalink](https://www.aussiewhvcompass.com/prep.html#luggage)

### 台灣帶（澳洲難買或貴）

[Section permalink](https://www.aussiewhvcompass.com/prep.html#main-content)

- **隱形眼鏡帶足全程份量**——澳洲配鏡需處方，看驗光師費時又貴。

- **亞系防曬（PA++++）與面膜**——澳洲防曬主打防曬傷不防曬黑，亞洲品牌難買。

- 慣用的保濕品、處方藥（附英文處方箋與原包裝，入境誠實申報）。

- 一套面試／正式場合的衣服；好的保暖層（亞洲便宜）。

- 轉接頭（澳規 I 型）數個。

### 澳洲買（更便宜或必須在地買）

[Section permalink](https://www.aussiewhvcompass.com/prep.html#main-content)

- 基本衣物：Kmart T 恤 $5–15；二手店（Vinnies、Salvos）更省。

- **工鞋／工靴與安全裝備**：規格要合澳洲職場要求，落地後買。

- 身體防曬 SPF50+（超市便宜大罐）、洗沐用品。

### 入境申報紅線

[Section permalink](https://www.aussiewhvcompass.com/prep.html#main-content)

澳洲生物安全檢查全球最嚴：**食品、藥品、木製品、種子、土壤相關物品一律誠實申報**——申報了頂多被沒收，沒申報被抓可罰款甚至影響簽證。成藥別大量帶（澳洲基本止痛藥一盒幾塊錢），中藥與肉製品風險最高。詳見官方入境須知：[ABF Can you bring it in](https://www.abf.gov.au/entering-and-leaving-australia/can-you-bring-it-in)。

行李建議整理自背包客社群共識與站長經驗（非官方）；申報規定為官方要求｜2026-08 查核

## 四、落地 72 小時

[Section permalink](https://www.aussiewhvcompass.com/prep.html#72h)

- **SIM 卡**：機場或超市買預付卡即可。打算跑偏遠地區的人，選用 Telstra 網路的電信（如 Boost）訊號覆蓋最廣（見[物價頁](https://www.aussiewhvcompass.com/cost.html#living)）。

- **交通卡**：各州各自的卡（Opal／myki／go card／SmartRider），機場或超商可辦。

- **緩衝住宿**：行前先訂好 **1–2 週**的過渡住宿（hostel 或短租）——這不是浪費錢，是讓你「不會被『今天不付就沒地方住』逼著踩租屋詐騙」的保險（見[住宿租屋](https://www.aussiewhvcompass.com/housing.html)）。

- **銀行開戶**：帶護照臨櫃開戶（有行前預開的人則是去驗證啟用），拿到卡片與 BSB/帳號。

## 五、第一週「三大號」：順序錯就被扣 45%

[Section permalink](https://www.aussiewhvcompass.com/prep.html#first-week)

**優先順序：TFN（一有地址就辦）→ 銀行帳戶 → myGov 綁 ATO → super 帳戶。**

- **TFN（稅號）第一優先**：申請**只需要護照與澳洲收件地址**（hostel 地址可用，不需要先有銀行帳戶）——一落腳就上 ATO 官網[免費線上申請](https://www.ato.gov.au/individuals-and-families/tax-file-number/apply-for-a-tfn)，最長 **28 天**寄達，這就是為什麼要第一週辦。任何收費「代辦 TFN」都是在賣你免費表格（見[防詐騙](https://www.aussiewhvcompass.com/scam.html)）。

- **還沒拿到 TFN 就找到工作？**在雇主的 TFN declaration 勾選「已申請 TFN」，依 ATO 的 28 天規則可先按正常稅率預扣；**完全沒申請也沒申報的人才會被 45% 預扣**。

- **銀行帳戶**：抵澳後儘快開好（薪資要入帳）；TFN 到手後回頭補登到銀行（否則利息被高額預扣）、交給雇主（勾選 working holiday maker）。

- **myGov**：註冊並連結 ATO——之後查 super 入帳、報稅全靠它。

- **super 帳戶**：**自己先選好一個**基金（比較管理費），入職時把帳戶資料給雇主——否則每換一個雇主就被開一個新帳戶，管理費多頭蠶食，離澳領回時還要先整併（見[報稅離澳](https://www.aussiewhvcompass.com/leave.html#super)）。

來源：[ATO TFN 申請](https://www.ato.gov.au/individuals-and-families/tax-file-number/apply-for-a-tfn)・[ATO WHM 專頁](https://www.ato.gov.au/individuals-and-families/coming-to-australia-or-going-overseas/coming-to-australia/working-holiday-makers)｜2026-08-28 查核

## 六、常見錯誤快查表

[Section permalink](https://www.aussiewhvcompass.com/prep.html#mistakes)

| 錯誤 | 代價 | 正解 |
| --- | --- | --- |
| 簽證還沒下就辭職、訂機票 | 審理變慢時進退兩難 | 核准信到手才動（[簽證頁](https://www.aussiewhvcompass.com/visa.html)） |
| 「有繳稅就有健保吧」 | 一次急診數百、住院一天數千 | 台灣不是互惠國，行前買保險（[健康安全](https://www.aussiewhvcompass.com/health.html)） |
| 拖著不辦 TFN | 28 天寬限用完就被 45% 預扣，退稅要等報稅季 | 一有澳洲地址（hostel 也算）第一週就辦 |
| 雇主叫你「順便開個 super」 | 帳戶越開越多、管理費蠶食 | 自選一個帳戶用到底 |
| 行李帶滿 30kg 衣服和成藥 | 用不到＋申報風險＋回程超重費 | 衣物在地買便宜，藥品少量附處方 |
| 落地才開始找住宿 | 被急迫感逼著踩詐騙 | 先訂 1–2 週緩衝住宿（[住宿租屋](https://www.aussiewhvcompass.com/housing.html)） |
